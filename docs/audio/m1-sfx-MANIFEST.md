# M1 sound effects: MANIFEST

- **Prepared:** 2026-10-08, by the Asset Manager (Grok Bot). Delivered into `/workspace/assets/m1-sounds/`; nothing was copied into any repo. Integration is the Developer's job.
- **License status:** **all 33 files are CC0 1.0 (public domain dedication).** Each one comes from a Freesound page whose license field I checked on 2026-10-08 as `creativecommons.org/publicdomain/zero/1.0/`. A snapshot of each page is in `licenses/freesound_pages/`. The CC0 legal code is in `licenses/CC0-1.0-legalcode.txt`. Nothing here needs attribution; credits are optional and listed in `/workspace/assets/CREDITS-draft.md`.
- **Style:** I chose realistic recorded foley (real plastic, bucket, bin and car-bonnet hits). I avoided synthetic or cartoon UI sounds, per the Game Director's direction.
- **Source quality caveat:** Freesound's lossless originals require a logged-in download. I used the public **HQ Ogg previews** (`cdn.freesound.org/previews/...-hq.ogg`, lossy) as originals. Before shipping, the Developer or Jared may want to log in and fetch the lossless originals from the same pages, then re-run the same trims (listed per file below; script at `/workspace/assets/work/snd/make.py`).
- **Audition caveat:** **I could not listen to these sounds.** I chose them from Freesound titles and tags plus signal analysis: onset detection, decay length, spectral centroid, and a waveform check. A human should audition them before they ship (see "Gaps / to verify").

## Processing (all files)
Each file went through the same chain:
1. Trim the segment from the preview.
2. Downmix to mono and resample to 44.1 kHz.
3. High-pass at 40 Hz. A few files also got a low-pass, as noted.
4. Apply a 2 ms fade-in and a short fade-out.
5. Normalize to **-1.5 dBFS sample peak**. Measured peaks after encoding land at -1.3 to -1.7 dBFS, so all stay under the -1 dBFS ceiling after Vorbis encoding.
6. Encode as Ogg Vorbis q6.

Every file is peak-normalized to the same level, so **relative loudness is set in-engine**. Use the "suggested volume_db" column: soft variants about -8 dB, player UI-type feedback -6 to -10 dB. Scale impacts further by collision impulse. The mean (RMS) level is listed so the Developer can see which files will feel louder at the same peak. The metal and cone-hard sets are denser and louder; the concrete set is very transient and feels quieter.

## Mapping to the current code (for the Developer)
- `scripts/stack_controller.gd`:
  - `print("click")` (lines 205, 274) → `sfx_cone_attach_click_0[1-3]`
  - `print("dull click")` (lines 283, 289, 457, 468, 492) → `sfx_dull_click_0[1-2]`
  - `print("knock")` (line 837, cap refusal) → `sfx_knock_0[1-3]`
- Impacts: choose a set by the other body's material: cone/barrel → `cone`, car (`hitter` group / `AnimatableBody3D`) → `metal`, sidewalk/curb → `concrete`, road/terrain → `ground`. Choose soft or hard by an impulse threshold. A starting point to tune: soft < ~2 N·s, hard above that. That number is a suggestion and has not been tested.
- Topple: play `sfx_cone_topple_0[1-2]` once when a stack of 3 or more pieces breaks or falls, at the base position. Let the per-piece impacts layer on top.
- For variants, use an `AudioStreamRandomizer` resource with `random_pitch` about 1.08 and `random_volume_offset_db` about 2. Loop must stay **off**; the Godot import default is `loop=false`, which I verified.
- Godot import of all 33 files: **verified clean** on a temp copy (`/tmp/assets-check/m1`, Godot 4.7.2 headless `--import`). All 33 load as `AudioStreamOggVorbis` with `loop=false`; see the two logs. This does not verify how they sound.

## Gaps / to verify
1. **Asphalt-specific impacts: not found.** No CC0 recording of plastic hitting asphalt specifically turned up. `sfx_cone_impact_ground_*` are plastic-on-hard-ground hits (one is a plastic bucket set down on hard ground) and are meant for asphalt and terrain. The `concrete` set comes from a source labelled "plastic concrete thud". A future improvement is to record a real cone dropped on asphalt, in-house and therefore CC0-compatible.
2. **Real traffic-cone recordings: none found as CC0.** The "traffic cone" searches returned only ambiences. The closest matches are hollow plastic box, bin and bucket hits.
3. **Cone-on-car (metal):** these are a *hand* hitting a car bonnet (396686) and a "car door hit" (340539). They approximate a light plastic object hitting a car panel and may sound too heavy. Audition them and lower volume_db if needed.
4. `sfx_cone_attach_click_03` is a seat-belt latch, so it may have a slight metallic edge. `sfx_dull_click_01` is a low-passed copy of `attach_click_01` (derived, same CC0 source). `sfx_dull_click_02` is tagged "ui" on Freesound but is a recorded thud.
5. `sfx_cone_impact_concrete_*` come from a "vinyl weight on floor" recording. The source says plastic/vinyl on concrete, but the object is denser than a hollow cone.
6. Topple has 2 variants, not 3. The third candidate (570688, plastic lids tumbling) sounded too small and bright on analysis (centroid ~4 kHz) and was left in `unused_candidates/`.
7. The originals are lossy previews; see the caveat at the top.
